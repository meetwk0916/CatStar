# Cat Coat Presets v1

Six curated Phase 0.1 coat presets derived from the same gray-white motion
master:

- gray-white tabby
- orange tabby
- solid black
- solid white
- calico
- tuxedo

Using one motion master keeps silhouette, timing, and action readability
consistent. The derivatives are deterministic working assets produced by
`scripts/build_cat_coat_presets.py`; they establish the runtime composition
model and can be art-directed further without changing passport data or scene
behavior.
