# Production model-sheet v1 generation request

Use case: stylized-concept

Asset type: dedicated CatStar production model sheet for the first-release
rounded short-haired cat; this is a new production-authority image, not the old
three-prototype comparison.

Input image: the existing three-column concept comparison is direction
reference only. Use only its left-column gray-and-white rounded short-haired
cat as the approved visual direction. Do not include or reuse the slender or
fluffy cats.

Primary request: create one identity-consistent pixel-art character model
sheet for a healthy adult rounded short-haired domestic cat. Show exactly
eight clearly separated views/poses of the same cat at one coherent scale:
right-facing neutral stand, left-facing neutral stand, front stand, rear stand
with head slightly turned, right-facing seated pose, front three-quarter
seated pose, right-facing awake resting pose, and a large front three-quarter
head study.

Identity lock: broad deep chest, compact substantial torso, naturally rounded
belly and hindquarters, short sturdy adult legs, wide cheeks, short neck,
natural small triangular ears, amber eyes, wider white muzzle, calm curious
expression, four white-socked paws, and a medium gray-and-white tabby ringed
tail. Believable adult domestic-cat anatomy and weight take priority over
mascot cuteness.

Marking lock: white muzzle; white chest continuing through belly; white lower
legs and all four paws; gray tabby crown, back, flanks, and tail; consistent
facial blaze and tabby stripe placement from view to view. Do not relocate or
remove markings between views.

Production lock: consistent ground/contact line for every full-body view;
consistent warm upper-left nighttime interior lighting; restrained dark soft
outline; crisp controlled pixel clusters; consistent pixel density suitable
for deriving `96x96` runtime cells.

Composition: clean 2x4 reference grid with generous padding, no overlaps. The
head study may use the final cell but must preserve the same face landmarks.

Scene/backdrop: perfectly flat solid `#00ff00` chroma-key background, uniform
edge to edge.

Constraints: no labels or text, no floor plane, no cast shadow, no gradient,
no texture, no reflection, no watermark, no extra objects. Keep all full-body
cats fully inside frame.

Avoid: slender torso, long body, long legs, tiny head, long neck, chibi kitten,
oversized eyes, fluffy long coat, breed-show exaggeration, inconsistent
anatomy, inconsistent markings, extra limbs, floating paws, painterly blur,
photographic texture, or third-party character resemblance.
