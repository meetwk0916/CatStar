# Rounded Short-Haired Production Model Sheet v1

**Status:** Approved production model sheet

This is a dedicated production-model candidate created after the older
three-prototype comparison established visual direction. It is not the old
comparison sheet renamed or promoted. The eight-view sheet locks one
gray-and-white rounded short-haired adult identity across opposing side views,
front and rear views, two seated views, awake rest, and a face study.

The chroma-key source is retained under `sources/`. The exact normalized
generation request is retained in `generation-prompt.md`. wakun approved the
sheet on 2026-08-08 before v12 action generation, then approved the derived
`96x96` cells in continuous desktop and mobile runtime review.

## Generation and provenance

- Generated on 2026-08-08 with built-in ImageGen in the project owner's Codex
  session; the provider did not expose a specific underlying model version.
- The left-column cat in
  `product-cat-prototypes-v1/concept-sheet-a-v2.png` was used as visual
  direction only. The slender and fluffy prototypes were explicitly excluded.
- No third-party character, brand, illustration, or photograph was requested
  as an input or imitation target.
